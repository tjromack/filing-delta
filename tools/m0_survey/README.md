# M0 survey scripts

Throwaway research tooling behind `docs/design/section-parser.md`. These are not production code. They're kept so
every observation in the design doc can be reproduced.

```sh
python tools/m0_fetch.py https://data.sec.gov/submissions/CIK0000320193.json ...   # submissions JSON (11 filers)
python tools/m0_survey/list_10k.py data/m0                     # 10-K history per filer
python tools/m0_fetch.py $(python tools/m0_survey/pick_sample.py data/m0)   # the 18-document sample
python tools/m0_survey/headings.py data/m0/*.htm               # every Item / named heading, with TBL/BOLD/LINK/ID flags
python tools/m0_survey/toc_links.py data/m0/*.htm              # do TOC #anchors resolve, and where to
python tools/m0_survey/dump_blocks.py FILE START END           # read leaf blocks by index
```

These need `lxml` (`uv pip install --native-tls lxml`). The sample URLs are recorded in `data/m0/sample-urls.txt`,
which is gitignored and regenerated by `pick_sample.py`.
