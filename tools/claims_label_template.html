How to label (press ?)

Each item is one highlighted clause from the filing's MD&A. The table under it is the audited (10-K) or interim (10-Q) statement figure for the same metric and period. Judge only the highlighted words, checking in order: (1) Is it the whole company, not a segment, product or region? (2) Is it this filing's own period? (3) Is it a plain GAAP figure? (4) Does the amount fit a table value at the precision written ("$383.3 billion" covers 383.25 to 383.35)? All four yes: M. Fails only 4: N. Fails 3: G. Fails 1 or 2, or it states a change rather than a total: X.

M · Matches
It states the company's consolidated total for this filing's own period, as a GAAP figure, and the amount equals a tagged value at the precision stated ("$6.9 billion" covers 6.85 to 6.95 billion).
N · No matching tagged value
Consolidated, this period, GAAP, but the amount isn't any tagged value at the stated precision.
G · Non-GAAP
An adjusted, organic, constant-currency or other non-GAAP measure.
X · Not checkable
A segment, subsidiary or region; another period; a change rather than a level; or not really the named metric. A code is optional.
U · Unsure
A valid answer. Add a note if you can say why.
